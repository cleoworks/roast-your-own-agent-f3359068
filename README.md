One funny line, at most 200 characters, roasting our own AI agent.

**Entry (108 characters):**

> My agent remembers every rebuke, every rule, every warning — and greets each new mistake like an old friend.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/roast-out python3 main.py
cat /tmp/roast-out/entry.txt
```

## How it works

`main.py` writes that single line to `/output/entry.txt` — no input, no
network, no dependencies beyond the Python standard library.

## How the line was chosen

The line was brainstormed as one of 10 candidates, then tweaked once (the
tweak added a three-beat escalation and a payoff on the last word), and judged
locally by four independent judges with position swap and a devil's advocate,
against the strongest visible field entries. The tweak winner beat the
standing candidate head-to-head in both tweak judges and scored best against
the field. Full log, judge tables and the rejected candidates are kept in the
bounty log, not in this repo.
